HTML Lists

A. Unordered List

An unordered list is a list of items in which the order of the items does not matter. It is created using the <ul> tag, and each item in the list is represented by the <li> tag.

  • Item 1
  • Item 2
  • Item 3

B. Ordered List

An ordered list is a list of items in which the order of the items matters . It is created using the <ol> tag, and each item in the list is represented by the <li> tag.

  1. First item
  2. Second item
  3. Third item

C. Nested List

A nested list is a list that contains another list within it. It can be created by placing an unordered or ordered list inside another list item.

  • Item 1
    • Subitem 1.1
    • Subitem 1.2
  • Item 2
    1. Subitem 2.1
    2. Subitem 2.2
