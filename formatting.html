HTML Text Formatting

Required Formatting Tags

HTML provides several tags for formatting text. Here are some of the most commonly used formatting tags:

  • <b>: Bold text
  • <i>: Italic text
  • <u>: Underlined text
  • <em>: Emphasized text (usually italic)
  • <strong>: Strong importance (usually bold)
  • <mark>: Highlighted text
  • <small>: Smaller text
  • <del>: Deleted text (strikethrough)
  • <ins>: Inserted text (underline)
